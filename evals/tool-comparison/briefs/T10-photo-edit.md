# T10 · Photo correction

Fix and finish `evals/tool-comparison/fixtures/coast-raw.jpg`, a photo of a sunset coast with a
lighthouse, a standing figure and a few birds. It has problems you should find and fix: exposure,
color, a tilted horizon and noise.

**Rules.** It must stay the same photograph. Correct it; don't repaint, add, remove or move
anything in the scene. Never overwrite the original file.

## Deliverables

| File | Spec |
| --- | --- |
| `coast-edited.jpg` | Corrected, horizon level, full resolution; crop only as much as leveling requires |
| `coast-instagram.jpg` | 1080 × 1350 px crop of the corrected photo, composed for a phone |
| `coast-caption.png` | 1600 × 900 px: the corrected photo with the caption "Port Ellery at golden hour" in the bottom-left, kept readable with a subtle dark gradient behind it |
| your editable source | if your tool keeps edits editable (layers, adjustment settings, a script); otherwise skip |

## When you're done

Put every file in the run folder you were given. Then write `REPORT.md` there, listing each file
and how you made it — including the corrections you applied, with amounts (for example the rotation
angle) — anything in this brief you didn't do or did differently and why, and anything you're
unsure about. Be exact: the report is checked against the files.
