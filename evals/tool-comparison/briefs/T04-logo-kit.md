# T04 · Logo and icon kit

A logo and the files a small business needs to start using it.

**Brand.** Tidewick Café is a small, fictional harbor-side café. Name: **Tidewick**. Tagline:
**Coffee by the harbor**. Colors: navy `#14263b`, lamp amber `#f2a541`, cream `#f7f1e5` as the
light background. Personality: warm, coastal, unfussy; avoid clichés such as anchors and ship wheels.

**The mark.** A simple symbol that hints at a lamp or a lighthouse light and at water. It must stay
recognizable at 16 × 16 px, so keep it bold and simple. Use at most two colors.

## Deliverables

| File | Spec |
| --- | --- |
| `logo-horizontal.svg` | Mark to the left of the wordmark "Tidewick", tagline beneath the wordmark |
| `logo-stacked.svg` | Mark centered above the wordmark and tagline |
| `mark.svg` | The mark alone, in color |
| `mark-mono.svg` | The mark alone, navy only |
| `favicon.ico` | Contains 16, 32 and 48 px images |
| `app-icon-1024.png` | 1024 × 1024 px, opaque (no transparency), square corners |
| `logo-sheet.png` | 1600 × 1200 px: every version on cream and on navy, plus the mark at its real 16, 32 and 64 px sizes |

The SVGs must be real vector files: no embedded raster images, and they must look the same on a
computer that doesn't have your fonts (convert lettering to outlines, or embed the font).

## When you're done

Put every file in the run folder you were given. Then write `REPORT.md` there, listing each file
and how you made it, anything in this brief you didn't do or did differently and why, and anything
you're unsure about. Be exact: the report is checked against the files.
