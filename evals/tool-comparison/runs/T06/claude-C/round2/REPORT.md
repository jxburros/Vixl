## Changes
1. **New field `instagram`**, labeled "Instagram handle": a required text field (`/FT /Tx`, `/Ff` 2) with an amber `*` and the tooltip "Instagram handle (e.g. @yourname)". To keep it right after Email without adding a row, the Email/Phone row became three columns: Email (rect x 54–264), Instagram handle (276–415), Phone (427–558). Email is narrower than before (was 54–344), but the sample address still fits at 11 pt. Nothing else on the page moved. It has no format check (for example, a leading `@`), because none was asked for.
2. **Slot options** are now `/Opt` = `7:00–7:30`, `7:30–8:00`, `8:00–8:30`, `8:30–9:00`, `9:00–9:30`, `9:30–10:00`, with real en dashes. As before, the field is a required combo and nothing is preselected (`/V` and `/DV` are empty).
3. **Tab order:** the widgets are still created in reading order, and the page keeps `/Tabs /R`. I checked the `/Annots` order with pypdf: performer_name, email, instagram, phone, act_type x4, performers, needs_mic, needs_amp, needs_keyboard, needs_projector, pieces, slot, photo_consent, signature, date.
4. **Sample:** same values as before, except `instagram` = `@driftwoodquartet` and `slot` = `8:30–9:00`. I checked with pypdf text extraction that both strings are present. The `fit_text` width assert passed, so every value fits at 11 pt. I rendered both PDFs with pdftoppm and checked them by eye: nothing is cut off or overlapping.

The code edits in `make_form.py` were the `SLOTS` list, the `SAMPLE` dict, the email/phone row (now three `text_field` calls), and adding `"instagram"` to the required-name list in `postprocess`.
