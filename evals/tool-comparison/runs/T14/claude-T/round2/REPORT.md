What was asked: move every lyric 0.25 s earlier, keep the title card starting at 0, and make chorus lines 25 % larger.

## Changes and how they were made (all in round2/build.py)
1. **Path:** the fixtures path is now one level higher (`../../../../fixtures`), because the script sits in round2/.
2. **0.25 s earlier:** I added `LYRIC_OFFSET = -0.25` and apply it to every LRC timestamp as it is parsed (clamped at 0). Section markers and the empty "clear" timestamp move with the lyrics, so the section label, the chorus/verse background switch and the "lighthouse" glow stay in sync with the lines. The new times are:
   - lyrics at 1.75, 5.25, 8.75, 12.25, 17.75, 21.25, 24.75 and 28.25 s;
   - the clear at 15.75 s;
   - section labels: Chorus 8.75–17.75, Verse 2 17.75–24.75, Chorus 24.75–32.00;
   - glow during 8.75–12.25 and 24.75–32.00.

   The last line still runs to the end of the song (32.00 s).
3. **Title card:** it still starts at 0. Its end is now set to the first lyric's time, so it runs 0–1.75 s instead of 0–2.00 s and doesn't overlap the first line. The original `TITLE_END = 2.0` constant was replaced by this computed value.
4. **Chorus lines 25 % larger:** I added `CHORUS_SCALE = 1.25` and two new ASS styles.
   - `CurrentChorus` is 72.5 px (was 58). Its side margins are 60 instead of 90, and it is positioned at y=305 instead of 320, so a wrapped two-line chorus line still clears the "next" line at y=450.
   - `NextChorus` is 40 px (was 32), used for the small preview line.

   A line counts as a chorus line when the section at its (shifted) timestamp is a Chorus. Verse lines and the title card are unchanged.

## Choices
- I read "every lyric" as the whole LRC timeline, so the section starts and the clear moved too. If only the lyric text had moved, the background and section label would change 0.25 s after the line they belong to.
- The "next" preview is also 25 % larger when the previewed line is a chorus line. For example, at 5.25–8.75 the verse line is shown with a 40 px chorus preview under it. I did this because a chorus line is the same line whichever slot shows it. If only the large current line should grow, change the `NextChorus` size back to 32 in the script.
- At 72.5 px, the two chorus lyrics wrap onto two lines, which was also true for most lines at 58 px.
