# Guides

[Documentation home](../README.md)

Task-oriented guides, one feature area each. They explain when to use a feature, show working
commands and operations, and state its limits. Exact syntax lives in the [reference](../reference/README.md);
end-to-end walkthroughs live in the [tutorials](../README.md#learn-by-making).
