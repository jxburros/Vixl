# Vixl evaluation re-run on Vixl 0.26.0 · 2026-10-12

> **The tool-comparison scores below are superseded.** Every lane was re-judged blind on 2026-10-13; see
> [the blind re-judging](2026-10-13-blind-rejudging.md). The runs, timings and Vixl issues found here still stand.

This repeats everything in `evals/` that earlier runs covered, on Vixl 0.26.0:

1. the **agent eval suite** (`evals/tasks`, now 31 tasks):
   - a reference replay in all four schema/tool modes;
   - a live agent run, with Claude subagents as the agent;
2. the **Vixl lane (V) of the tool comparison** (`evals/tool-comparison`, 16 briefs): round 1, the round-2
   revision, and blind judging against the other lanes.

**See the work:** [the gallery](2026-10-12-gallery.md) shows every lane's deliverables for both rounds of all
16 tests side by side, with their scores.

The earlier records are [2026-10-05](2026-10-05-full-evaluation.md) (Vixl 0.18.0, every lane) and
[2026-10-06](2026-10-06-vixl-0.20-tool-comparison.md) (Vixl 0.20.0, V lane only). The W, C and T lanes did
not change, so their 2026-10-05 runs and scores stand.

**Not run**, as before:
- the API-driven `--agent claude` mode, because no `ANTHROPIC_API_KEY` is configured;
- the G, D and K app lanes;
- the Codex/GPT half of every pair.

Every agent and judge was a Claude Code subagent on `claude-opus-5-5`.

**Friction the live agents hit on 0.26.0** (from `agent-log-{a,b,c}.json`):

The three errors were all guessed field names:
- `page set` on a new deck fails because a fresh document has no page 1 yet; it needs `page add` first;
- `transform` needs `matrix`;
- `reparent` takes `into`, not `parent`.

Schemas and results:
- `vixl_workflow_schema` returns about 104 KB with no way to ask for one action. That is too big for
  the client, so the agent had to cut the saved output down with `jq`.
- The form-fill result says `invalid: [2]` without saying whether 2 is a row or a line number, and it
  doesn't report the number of pages written.
- A pre-existing font warning makes unrelated edits report `validation_failed` (copy-between-documents,
  restore-deleted).

Objects:
- The object checks miss a sub-object's missing required part (cactus pot). The guitar's declared
  neck-to-body proportion is never measured.
- Group bounds go stale after children move (detect-cat, dog).
- Setting width and height on a path drawn at the origin scaled its data, so a tail shrank to a dot.

Defaults and styling:
- A new document picks a palette, fonts and decoration nobody asked for. There are stray decoration dots
  outside the safe area (font-pairing, roll-applied), and the seed palette differs between create and
  `layout-apply` (layout-filled).
- The default chart padding (16 px) ignores the 25 px safe area, so a new chart fails `vixl_check` with
  6 errors.
- `organic-shape` adds a 1 px outline by default.
- Creating from a template doesn't install its fonts.
- Pathfinder keeps its source shapes as hidden layers.

## 2. Tool comparison: Vixl lane

### Method

As on 2026-10-06:
- **Agents.** One fresh subagent per round, with the kit's standard kickoff prompt and V lane rule and no
  coaching. The old V folders were moved out first, so no agent could read an earlier report.
- **Judges.** One judge per test:
  - rebuilt the other lanes from their committed sources in a scratch folder;
  - scored fidelity and craft blind on `inspect_outputs.py --blind` copies before opening the key;
  - ticked hard checks and scored honesty, editability and revision against the `TESTS.md` answer keys;
  - replaced the V row in `runs/<T>/scores.csv` and rewrote `runs/<T>/JUDGE.md` with a "Changes since
    earlier Vixl runs" table.
- **Other lanes.** Every judge's blind score for an unchanged lane either matched its 2026-10-05 score or
  was noted and left as recorded.
- **Load.** About 8–12 agents shared one MCP server at peak, and no call timed out.
- **Reports.** Every round-1 and round-2 agent was refused when writing `REPORT.md` itself ("subagents
  should return findings as text"), so each returned its report and the orchestrating session saved it
  verbatim.

## What improved

- **The 0.20.0 follow-up list is nearly all fixed.** Judges confirmed each of these on scratch documents:
  - contrast check crash on half-pixel text (T03, T16);
  - `check` skipping full-canvas path layers (T01);
  - PPTX bold flag and unfilled shapes (T05);
  - open stroked paths filled white (T15);
  - effects running after rotation, and the `temperature`/`tint` balance (T10);
  - `font-fallbacks` ignoring `target` (T07);
  - LANCZOS halos, now mostly gone (T15);
  - video audio resampled to 24 kHz (T14);
  - sheet export reporting the frame size (T13);
  - GIF export reporting the wrong frame count (T12);
  - PDF Title taken from the first text layer (T03);
  - `drawing stroke` using canvas coordinates in a moved group (T11).
- **New features removed whole workarounds:**
  - **T15:** seamless scatter, so the agent no longer computes positions in Python and the lane rule is clean.
  - **T07:** lookup maps in merges, so there is no CSV preprocessing.
  - **T14:** lyric section styles, so the larger chorus survives a rebuild.
  - **T16:** decimal tables, so round 2 needs no manual fixes.
  - **T12:** keyframe sampling, so the beam is re-timed in one operation.
- **Cheaper to drive.**
  - Median round-1 calls fell from 41 to 31.5, and round-1 minutes from 4.5 to 3.8.
  - T14 took half the time, and T11 and T15 took about half.
  - On the agent eval, the 18 original tasks had 0 errors.
- **T07 passes all hard checks for the first time,** and T09's craft recovered to 4.

- **7 of 16 tests** scored the same as on 0.20.0: T01, T06, T08, T10, T12, T13 and T14.

## Vixl issues found (for follow-up)

Each was reproduced by a judge or the orchestrator on a scratch copy. File references are the judges'.

Rendering and export:
- **PPTX export crashes on a per-corner `radius` list.** `src/vixl/pptx_export.py:272` does
  `radius - pad` on the list, giving a raw `TypeError` traceback, not a JSON error. PDF and SVG export
  the same shape fine (T05).
- **Plain text-layer `tracking` is not scaled** by `_scale_layer` in `src/vixl/proxy.py`. Scaled previews
  and link layers draw tracked text too wide, for example 609 px against 566 px, which clips "COFFEE BY
  THE HAR" (T03, T04). Exports are correct.
- **Adding `tracking` to plain text drops it about 28 px.** It converts to rich text with line height 1.0
  (T03).
- **Tonal effects truncate.** `render.apply_effect` ends with `np.uint8(...)` and passes 8-bit values
  between effects, so a white-balance, levels and curves stack ends about 2 levels darker than in
  floating point (T10).
- **Rotated groups are rasterised and then resampled,** giving frayed edges against the SVG (T15).
- **New layers are exported after existing ones in PDF reading order.** The default `vixl_check` doesn't
  run `accessibility`, so it isn't flagged (T06).
- **Smaller export gaps:**
  - form text fields use Helvetica in `/DA`;
  - SVG shapes carry a hidden stroke;
  - replaced fonts stay embedded through undo history (T06, T04, T12).

Checks:
- **The contrast check reports 1.00:1 for text inside a `stack` group.** `measure.measure` hides siblings
  and the stack reflows (T07).
- **`vixl_check` ignores timeline visibility.** It reports overlaps and contrast between layers that are
  never on screen together (T14).
- **Loop-seam warnings on play-once intros.** The lyric build sets `loop: 0` on a play-once video, and
  play-once intros in looping GIFs raise 4–10 `motion.loop-seam` warnings with no way to say "play once"
  (T12, T14).
- **Stack-total labels fail Vixl's own legibility check.** They are drawn at 0.85 × `font_size`
  (`charts.py:735`), and there is no automatic fix (T08).
- **Rule and suite gaps:**
  - a `relation` rule with `bounds: "ink"` measures a path's box;
  - an `ink` rule with no background always reads 1.0;
  - an unknown rule key gives "Unknown check field" with no field name;
  - assertions can't compare a layer edge (T01, T02).
- **Smaller check issues:**
  - the safe-area check rounds outward on fractional positions (T03);
  - `merge-impose --check design` repeats waived findings unmarked (T07);
  - the `drawing` check passes with 5.8 % added ink (T11);
  - the layout check message prints "23.759999999999998 px" (T02).

Layout, data and editing gaps:
- **`pattern-scatter`:**
  - a new `count` gives a new spacing and a whole new layout, with no way to thin in place;
  - `count` is a ceiling, not a target;
  - there are no source weights or exclusion (T15).
- **`table-data` redraws throw away per-cell edits** without warning. There is no per-row style and no
  spanning note row. Decimal alignment is off by up to 1.7 px, from ink-width maths and rounding. The
  header rule has no clearance setting (T16).
- **There are still no tab stops or dot leaders** (BLK-07) (T16).
- **`adapt-layout`:**
  - re-anchors but doesn't re-compose;
  - doesn't treat `1080x1920` as a story;
  - splits text groups on wide sizes with no check finding (T02, T09).
- **`drawing`:**
  - `edge_closes` can't split regions when a line stops short of the edge;
  - auto gap closing leaves a 60 px gap;
  - `drawing stroke` smooths through corner points by default, and the chimney example in
    `docs/drawing.md` would come out rounded;
  - fills don't follow stroke edits;
  - tilt is over-corrected by 0.2° (T11).
- **No data flow** from a chart to other charts or to text (T08).
- **No CSV-driven PNG-per-row export over MCP.** It is CLI only (T07).
- **No photo levelling help:** nothing measures the horizon or crops a rotated layer to its filled area
  (T10).
- **Links:**
  - link sources are saved as workspace-root paths until `links-relink` is run;
  - `vixl dependencies` doesn't list link-layer sources (T04).
- **New documents seed an off-brand random palette and style** with unused swatches (T09; also seen in
  the live run).
- **Layout and text defaults:**
  - `event-poster` breaks "November / 12";
  - layout palettes override an explicit background silently (T02);
  - there is no balanced line wrapping (T14);
  - auto-sized centre-aligned text grows to the right on `text-set` (T03).

Tooling:
- **The Vixl MCP server writes `.vixl-suite-passes.json` at the workspace root,** which `.gitignore` doesn't
  cover.
