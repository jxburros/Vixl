# Tool comparison re-run on Vixl 0.20.0 · 2026-10-06

The [tool comparison](../evals/tool-comparison/README.md) ran on Vixl 0.18.0 on 2026-10-05
([results](2026-10-05-full-evaluation.md#2-tool-comparison)). This re-run repeats the **Vixl lane (V)**
of all 16 briefs on Vixl 0.20.0. The other lanes (W web code, C Python, T CLI tools) did not change,
so their 2026-10-05 runs and scores stand.

## Method

- **Same setup as before.** Each run was a fresh Claude Code subagent on `claude-opus-5-5`. It got the
  kit's standard kickoff prompt and V lane rule, with no coaching and no nudges. The Vixl MCP server was
  v0.20.0 with `--tools core --schema slim` and the repository root as its workspace. Round 2 ran in a
  fresh session that had only the round-1 files.
- **Judged per test by a separate subagent.** Each judge regenerated the other lanes' deliverables
  from their committed sources in a scratch folder, scored fidelity and craft blind on
  `inspect_outputs.py --blind` copies before opening the key, and then ticked hard checks and scored
  honesty, editability and revision against the `TESTS.md` answer keys. The judge then replaced
  the V row in `runs/<T>/scores.csv` and rewrote `runs/<T>/JUDGE.md`, adding a "Changes since the
  Vixl 0.18.0 run" section.
- **Blind scoring was partial in places.** File sizes or extra folders gave some lanes away (T03,
  T10, T14). T01's W deliverable could not be rebuilt, because its `picture.svg` was never committed,
  so T01's V run was judged against the rubric and C alone. Where a judge's blind score for an
  unchanged lane differed from its 2026-10-05 score, the old score was kept and the difference was
  noted in that test's `JUDGE.md`.
- **Times are less inflated than before.** About 3–8 agents shared one MCP server this time, against
  about 15 on 2026-10-05. Tool-call counts are still the fairer cost measure.

## What it says

- **0.20.0 closed almost every product gap the 0.18.0 run found.**
  - Hard checks went from 89/96 to 95/96, and every run but one passes all of them.
  - All six earlier hard-check failures trace to fixes since then: RGB PNG export, TrimBox and
    BleedBox, the shell palette, drawing import and gap closing.
  - The one miss left is T07: Sam Okafor's badge drops the empty company line but doesn't re-centre
    what's left. 0.20.0's `stack` can do that, but the agent didn't use it.
- **Revision is now Vixl's strongest area.** Median editability rose from 4 to 5, with 13 of 16 runs
  at 5. T07, T08, T13 and T14 became data or parameter edits:
  - **T07:** a CSV edit plus a re-run of the merge.
  - **T08:** one `chart-data` cell.
  - **T13:** one `frames-edit`.
  - **T14:** one `offset` field.
- **Revisions stay put.** Round 2 again kept the most of the original: T15 kept 87 % of its ink, against
  40 % for W and 11 % for C, and most diffs show change only where it was asked for.
- **It costs less, but still more than code.**
  - Median round-1 time fell from 8.1 to 4.5 minutes and tool calls from 54 to 41; round-2 time
    fell from 4.5 to 2.5 minutes.
  - The code lanes still need about a third as many calls (W 15, C 14 in round 1).
  - Lower contention explains part of the time drop, not the call drop.
- **Craft is unchanged at a median of 4.**
  - It fell in T05, T09 and T12. In T05 the cause is a PPTX bold bug; T09 and T12 are plainer
    designs from the new agents.
  - It rose in T06 and T13.
  - W still leads on craft where both ran.
- **Reports are honest in all 16 runs.** The slips judges found were small: a margin of 0.97 in that was
  0.70 in (T03), "mono" audio that was stereo (T14), a leader gap given as 34 px that ranged from 25
  to 47 px (T16).
- **Lane rule.** Two runs used a script for more than reading inputs and checking outputs:
  - **T07:** prepared role colours and labels in the CSV.
  - **T15:** computed motif positions.

  Both disclosed it, and neither had a Vixl feature to use instead (no lookup in a merge, no
  seamless scatter). Judges noted it and didn't lower a score.

## Vixl issues found (for follow-up)

Correctness:
- **The contrast check fails on text at half-pixel positions** ("boolean index did not match") and
  reports only a warning, so the overall check still passes (T03, T16; explorations 01, 08, 09).
- **`vixl_check` skips any non-text layer whose box covers the canvas** (full-canvas path shapes are
  treated as background) and still reports the reduced number as `layers` (T01).
- **PPTX export:**
  - Plain text in a bold registered face is written without `b="1"`.
  - Shapes with no fill export white (T05).
- **Open stroked paths get a white fill by default**, leaving slivers that no check flags (T15).
- **Effects run after a layer's rotation**, so denoise sees smoothed grain and under-corrects (T10).
- **`temperature` is too weak and `tint` too strong:**
  - At `temperature` 100 grey moves only ±2 levels.
  - `tint` turns blacks magenta.
  - There is no multiplicative white balance (T10).
- **`font-fallbacks` ignores `target`**, so a document keeps one fallback list, and unused fallback
  fonts stay embedded (T07).
- **Rendering and export details:**
  - Resampled layers get a bright halo in PNG exports (LANCZOS and bicubic overshoot) (T15).
  - Video audio is always resampled to 24 kHz (T14).
- **Small mistakes in what Vixl reports:**
  - Sheet export reports the frame size instead of the sheet size (T13).
  - GIF export reports frame counts before identical frames are merged (T12).
  - PDF Title comes from the first text layer (T03).

Gaps agents worked around:
- **`adapt-layout`:**
  - It leaves story text in the 250 px bands, stretches decoration unevenly, separates rules from
    the text they belong to, and sets banner text at 3 px (T02, T09).
  - The safe-area check only runs when `safe_area=` is passed.
- **Links in a copied `.vixl` keep pointing at the original's files**, with no relink option (T04).
- **No tab stops, decimal tabs or dot leaders, and text can't be placed by its baseline** (T16).
- **Data doesn't flow between charts:** no binding from one chart to another or into text, so totals
  and callouts are typed by hand (T08). There is also no warning when series colours override a
  new colour list.
- **Merges can't do lookups or change case** (T07).
- **No seamless scatter:** the guide's pattern recipe gives a grid (T15).
- **Drawing tools:**
  - `drawing stroke` takes canvas coordinates inside a moved group.
  - `drawing fill` can't use the canvas edge as a boundary.
  - Automatic gap closing bridges curves with straight lines (T11).
- **The legibility check judges full-size sheets and infographics as 320 px thumbnails**, flagging
  dozens of labels as "fix" (T04, T08).
