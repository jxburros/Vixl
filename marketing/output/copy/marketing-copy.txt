Ideas become editable.

Vixl is a programmable design studio for AI agents that creates, checks and delivers layered graphics, documents and motion.

SHORT DESCRIPTION
Give your agent a design studio. Vixl turns creative work into editable documents and atomic operations through MCP, CLI, Python or REST. Build graphics, charts, diagrams, decks, fillable PDFs and animation; run checks, review the render and deliver the files with their editable masters.

PRODUCT DESCRIPTION
Vixl brings design into an agent's workflow. Text, shapes, images, masks, effects, variables and pages live in a layered .vixl document with branching history. The same canonical operations work across MCP, a command-line interface, Python and REST. Create original artwork or start with layouts, templates and reusable containers. Turn data into editable charts and routed diagrams, build presentations with speaker notes, or make fillable PDF forms. Use typed recipes and CSV-driven production for checked variations. Animate with keyframes, character pose keys, cameras and audio; package app states with themes, transitions and reduced-motion stills. Save design requirements as suites, inspect the findings and visually review the result before exporting. Unpack documents into readable JSON and assets for Git review. Core authoring runs locally; AI generation and vision use explicitly configured external providers.
