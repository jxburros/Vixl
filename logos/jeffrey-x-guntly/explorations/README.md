# Jeffrey X Guntly — logo explorations

Every design is an editable `.vixl` document with a PNG export beside it.

- `1-improve/`: the traced original, improved:
  - 01 refined spacing
  - 02 forest and parchment
  - 03 gold foil
  - 04 woodcut seal
  - 05 J·X·G monogram
- `2-remake/`: rebuilt from an imagined brief with real typefaces:
  - 01 IM Fell vine
  - 02 Didone diagonal
  - 03 crossed thorns
  - 04 ex libris
  - 05 crossroads seal
- `3-radical/`: new forms with the same gothic-botanical mood:
  - 01 thorn sigil
  - 02 tarot card
  - 03 sumi brush X
  - 04 illuminated initial
  - 05 monoline
  - 06 rose window

The lettering in `2-remake` and `3-radical` is font outlines, not live text. To change the wording, edit the
generator scripts in each `source/` folder and rebuild. The scripts emit Vixl operation batches applied with
`vixl --project FILE apply ops.json`.

The imagined brief behind `2-remake`:

> A personal mark for Jeffrey X Guntly, a writer and maker of dark, storybook-flavoured work. It should feel
> literary and hand-crafted, a little gothic and enchanted, like something growing out of an old book. The X is
> the pivot of the name, a crossing or crossroads, so make it the point where nature takes hold of the letters.
> A thorny, living vine should grow through the name. It has to work in one colour, from a book spine or
> bookplate up to a poster.
